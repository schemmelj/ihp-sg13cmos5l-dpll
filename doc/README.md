# Documentation

- `testchip_documentation.pdf`: Comprehensive standalone testchip manual covering circuit architecture, floorplan, power distribution, SPI protocol, post-layout verification, and laboratory measurement breakout setup.
- `Specification.md`: Detailed electrical, physical, and layer density target specifications.
- `Datasheet.md`: High-level architectural overview, features, and electrical performance summary.
- `info.json`: Machine-readable IP metadata, category/subcategory, technology, and release definitions compliant with IHP Open-Silicon-MPW.
- `TRL-Mixed-Signal-IP.md`: Technology Readiness Level (TRL) quality assessment scorecard (TRL 5 verified).
- `pinout.md`: Complete bondpad coordinate table, pin directions, voltage levels, and pad cell types.
- `figures/`: High-resolution layout, floorplan, and simulation figures.
