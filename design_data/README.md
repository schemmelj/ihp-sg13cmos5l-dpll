# Design Data

This directory contains the primary design source and deliverable files for the IHP SG13G2 DPLL testchip:

- `gds/`: Full-chip GDSII layout files (`FMD_QNC_dpll_testchip.gds` and `FMD_QNC_dpll_testchip.gds.gz`).
- `def/`: Complete placed-and-routed DEF (`dpll_testchip.def`).
- `cdl/`: Transistor-level CDL schematic netlist (`dpll_testchip_schematic.cdl`).
- `verilog/`: Synthesizable SystemVerilog RTL and post-layout gate-level netlist.
