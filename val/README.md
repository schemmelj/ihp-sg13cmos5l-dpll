# Validation Data

This directory contains sign-off verification reports and multi-corner simulation artifacts:

- `drc/`: Foundry DRC sign-off report using IHP `sg13g2.lydrc` (0 errors).
- `lvs/`: Transistor-level LVS sign-off report using IHP `sg13g2.lvs` (matched, pure bondpad comparison).
- `sim/`: Post-layout multi-corner back-annotated simulation logs and summary scorecard across Typical, Fast, and Slow PVT corners.
